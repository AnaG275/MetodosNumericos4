# 📚 Métodos Numéricos
### Los métodos numéricos son técnicas matemáticas que permiten obtener soluciones aproximadas a problemas que no se pueden resolver de forma exacta o analítica. Se utilizan ampliamente en ingeniería, física, computación y ciencias aplicadas para resolver ecuaciones, sistemas de ecuaciones, integrales, derivadas y modelos matemáticos complejos.

Su importancia radica en que muchos problemas del mundo real no tienen una solución exacta o son demasiado complejos para resolverse manualmente, por lo que estos métodos permiten obtener resultados muy cercanos a la solución real mediante procesos iterativos y algoritmos computacionales.
